# M1b pre-registration: is it F's stream or F's hot table that harms the neighbour?

Written **before measurement**. M1's registered secondary reading found the harm
flat across a 16× stream-rate range, which a stream-rate effect cannot be. The
constant across those arms is F's 256 MiB hot table. This tests that directly.

**This comparison is among F configurations, so it does not depend on M1's failed
positive control** — it asks which *component of F* moves V, not whether V is
harmable in absolute terms.

## Arms

Victim as in M1 (`pointer_chase`, 170 MB, cpu8). F on cores 32–47, 16 workers.
n=6, arm order rotated.

| arm | F's stream | F's hot table | isolates |
|---|---|---|---|
| **V** | — | — | baseline |
| **V+F_big** | 256 MiB CXL | **256 MiB** | M1's V+F16, reproduced |
| **V+F_small** | 256 MiB CXL | **4 MiB** | stream held, table removed |
| **V+F_notstream** | **none** (`--mode hot-probe`) | 256 MiB | table held, stream removed |

`--hot-bytes 4m` instantiates 4 MiB (power-of-two entry rounding, ×16 B), well
inside the LLC and small enough not to displace V.

## Pre-registered readings

| outcome | verdict |
|---|---|
| `V+F_small` ≈ 1.00 **and** `V+F_notstream` ≈ `V+F_big` | **the hot table does it.** The harm is F's reuse structure, not its stream, and a stream-scoped label cannot remedy it. Adverse to the three-party frame, and registered to be reported as the headline if it happens. |
| `V+F_small` ≈ `V+F_big` **and** `V+F_notstream` ≈ 1.00 | the stream does it after all; M1's flatness needs re-explaining and the three-party frame survives |
| both intermediate | additive; report the split |
| neither reproduces `V+F_big` | the effect is not F at all; report and stop |

**Threshold:** "≈ 1.00" means < 1.03× (M1's baseline CoV was 0.11%, so 3% is
generous); "≈ `V+F_big`" means within 0.02× of it.

**Registered caveat:** shrinking the hot table also makes F's probes cheaper, so
`V+F_small` runs faster and streams *more* per unit time. That biases the test
**toward** finding a stream effect, so a null there is conservative. F's achieved
stream bandwidth is recorded per arm to quantify it.

## Out of scope

CAT masks; H2 or flush-behind arms; any absolute claim about whether V is
harmable on this host — M1 already showed this geometry cannot demonstrate that,
and nothing here changes it.
